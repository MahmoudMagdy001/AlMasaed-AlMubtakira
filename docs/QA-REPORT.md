### 2.2 تحسينات الأداء المطبقة
1. **التحميل المسبق لخطوط Tajawal (Font Preloading):**
   - تم بناء إضافة مخصصة في Vite تحقن تلقائياً وسوم `<link rel="preload" as="font" type="font/woff2" crossorigin="" href="/assets/tajawal-arabic-400-...">` و `700` في ترويسة جميع صفحات HTML الثابتة الـ 35، مما أزال وميض النصوص (FOIT/FOUT) وخفّض زمن LCP إلى أقل من 1.1 ثانية.
2. **منع انزياح التخطيط التراكمي (Zero Cumulative Layout Shift - CLS = 0.00):**
   - تثبيت أبعاد الصور والأيقونات.
   - استخدام مساحات محجوزة مسبقاً لعناصر الترويسة وأزرار التواصل العائم.
   - استخدام `font-display: swap` مع أوزان مطابقة لمنع إعادة حساب مساحات النصوص.
3. **التوليد الثابت للواجهات (SSG Prerendering):**
   - جميع الصفحات الـ 35 مبنية مسبقاً بصيغة HTML ثابتة ومخدومة فوراً من شبكة التوزيع (CDN) بدون انتظار عمليات بناء وقت التشغيل.

## 3. تدقيق الحزم البرمجية (Bundle Splitting & Isolation)

- **عزل محرّر المقالات (TipTap) ولوحة التحكم:**
  - تم عزل حزمة TipTap (`vendor-tiptap`: 688 KB غير مضغوط / 216 KB gzip) ومحرر المقالات `PostEditPage` بالكامل داخل كتل برمجية منفصلة تُحمّل عند الطلب فقط (`React.lazy`).
  - تم استبعاد حزم لوحة التحكم والمحرر من قائمة التحميل المسبق التلقائي (`modulePreload.resolveDependencies`)، مما يضمن أن زائر الموقع العام لا يقوم بتحميل أي بايت إضافي خاص بلوحة التحكم.
- **حجم ملف التنسيق العام (CSS):**
  - ملف التنسيق `app-DfV8K7lP.css` بحجم 71.11 KB فقط (نحو 12.4 KB gzip)، متضمناً كافة ألوان وتدرجات ورموز نظام التصميم المعتمدة.

## 4. إمكانية الوصول وتجربة المستخدم (Accessibility - WCAG 2.1 AA)

- **أداة axe-core:** فحص آلي لكافة المكونات أسفر عن **0 مخالفات حرجة و0 مخالفات خطيرة**.
- **التنقل الكامل عبر لوحة المفاتيح (Keyboard Navigation):**
  - رابط القفز المباشر للمحتوى الرئيسي (`<SkipToContent />` مرتبط بـ `#main-content`).
  - توفير حلقة حبس التركيز (`useFocusTrap`) في القائمة الجانبية للجوال (`Drawer`)، النوافذ المنبثقة (`Dialog`)، ومستعرض الصور المكبر (`Lightbox`)، مع دعم كامل للإغلاق بمفتاح `Escape`.
- **مؤشر التركيز البصري (:focus-visible):**
  - حلقة تركيز متناسقة وعريضة (`--focus-ring: 0 0 0 3px rgba(94, 193, 240, 0.45)`) تظهر لرواد لوحة المفاتيح دون التأثير على مستخدمي الفأرة واللمس.
- **التباين اللوني (Color Contrast Compliance):**
  - نصوص العناوين على الخلفية البيضاء: 15.3:1 (يتجاوز معيار AAA البالغ 7:1).
  - نصوص المتن على الخلفية البيضاء: 8.6:1 (يتجاوز معيار AAA).
  - النصوص الثانوية المساعدة: 4.6:1 (يتجاوز معيار AA البالغ 4.5:1).
  - عدم استخدام اللون السماوي `#5ec1f0` كنص على خلفيات فاتحة إطلاقاً.
- **تقليل الحركة (prefers-reduced-motion):**
  - كود CSS يتجاوب مع تفضيل المستخدم في نظام التشغيل لإلغاء وتصفير زمن الحركات والانتقالات (`animation-duration: 0.01ms`, `transition-duration: 0.01ms`) وتحويل التمرير إلى فوري (`scroll-behavior: auto`).
- **التسلسل الهرمي الدلالي (Semantic HTML):**
  - فحص صارم يؤكد وجود `<h1>` وحيد ودقيق في كل صفحة من صفحات الموقع الـ 35، مع تدرج صحيح إلى `<h2>` و `<h3>`.
  - تسميات ناطقة بلغة عربية دقيقة (`aria-label`, `aria-labelledby`, `sr-only`) لجميع الأزرار والملاحة وروابط التواصل السريع.

## 5. التوافق عبر المتصفحات والأجهزة (Cross-Browser & Responsiveness)

تم التحقق من التوافق عبر المحاكاة والاختبار على:
- **المتصفحات:** Google Chrome, Safari (iOS/macOS), Mozilla Firefox, Microsoft Edge, Samsung Internet.
- **أحجام الشاشات:**
  - هواتف صغيرة: 360px - 390px (iPhone SE, Galaxy A).
  - هواتف حديثة: 393px - 430px (iPhone 14/15/16 Pro, Galaxy S24).

- **ثنائية اللغة والاتجاه (RTL / LTR):**
  - العربية هي اللغة الأساسية (RTL) مع تطبيق الخصائص المنطقية CSS (`ms-`, `me-`, `ps-`, `pe-`, `start`, `end`).

## 6. الفحص الوظيفي (Functional QA)

1. **نموذج التواصل (`/contact` و `/en/contact`):**
   - التحقق من صحة الحقول بالاعتماد على Zod و React Hook Form.
   - إظهار رسائل الخطأ بوضوح وربطها بالحقول لسهولة قراءتها بواسطة قارئات الشاشة.
   - حقل مصيدة المخترقين (Honeypot) لمنع الرسائل العشوائية والسبام بدون إزعاج المستخدم باختبارات كابتشا معقدة.
   - تخزين الرسائل بنجاح في جدول `messages` في قاعدة البيانات.
2. **قنوات الاتصال المباشر:**
   - الرقم الموحد `920000000` مرتبط برابط اتصال نظامي `tel:920000000`.
   - زر واتساب يفتح المحادثة بصيغة الرابط الدولي الرسمي `https://wa.me/966500000000`.
3. **شريط وزر التواصل العائم:**
   - يظهر بسلاسة بعد تمرير 250 بكسل، ويقع في الزاوية السفلية المريحة للإبهام دون حجب عناصر النماذج أو أزرار الإرسال.
4. **المدونة:**
   - فلترة المقالات حسب التصنيفات، الترقيم وتوزيع الصفحات، والتحقق من مشاركة الروابط.
5. **معرض الأعمال:**
   - استعراض الصور عبر الـ Lightbox مع دعم التمرير باللمس، والتنقل بأسهم لوحة المفاتيح مراعياً اتجاه القراءة العربي، والإغلاق بـ Escape.

## 8. التدقيق الأمني (Security Pass)

1. **حماية أسرار المشروع (Zero Secrets in Bundle):**
   - فحص آلي شامل لمجلد التوزيع `dist/` أثبت خلوه التام من أي مفاتيح سرية، مفاتيح Service Role، أو بيانات حساسة. المفتاح الوحيد المستخدم هو مفتاح Anon العام المسموح به في المتصفح.
2. **سياسات أمان قواعد البيانات (Row Level Security - RLS):**
   - مفعلة على كافة جداول Supabase الـ 12 مع تحديد صارم لصلاحيات القراءة العامة، وحصر صلاحيات التعديل والإضافة والحذف بالمستخدمين المصرح لهم فقط.
3. **ترويسات الأمان (Security Headers in Vercel):**
   - تم تفعيل سياسة حماية المحتوى التقريرية `Content-Security-Policy-Report-Only`.
   - `X-Frame-Options: SAMEORIGIN` لمنع هجمات Clickjacking.
   - `X-Content-Type-Options: nosniff` لمنع تزييف أنواع الملفات.
   - `Referrer-Policy: strict-origin-when-cross-origin`.
4. **ملف robots.txt والتوجيه:**
   - حجب صفحات لوحة التحكم (`Disallow: /admin`) وصفحة دليل الهوية الداخلية (`Disallow: /_styleguide`).
   - توفير مسار خريطة الموقع الصحيح `Sitemap: https://almubtakirah.com/sitemap.xml`.
